URL canónica: https://github.com/Maybe-Sama/laud-investment-lab

```bash
git clone https://github.com/Maybe-Sama/laud-investment-lab.git
cd laud-investment-lab
python -m investlab doctor
python -m unittest discover -s tests -v
python -m investlab demo
claude
```

Pedir a Claude: «Lee `CLAUDE.md` y `docs/ROADMAP.md`, ejecuta las pruebas y continúa la fase 1. Prohibido realizar trading real».

No incluir tokens ni claves en el repositorio. Las carpetas `.data/` y `upstreams/` no se versionan.
